# Changelog

All notable changes, newest first. Versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-10-23

The first release.

### Added

- Native macOS desktops as a grid of any size up to 16 desktops, moved through with `ctrl+cmd+arrows`.
- A HUD with the grid that stays still while the desktop changes underneath, shown only for the app's own keys.
- Previews of every desktop, composed from its windows at launch and refreshed as you move around.
- Instant switching, with no slide animation.
- A settings window in the menu bar, applied as you change it, with key combo recording.
- Fast presses fold into one jump, so the grid never runs ahead of the screen.
